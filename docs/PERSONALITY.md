# Create your assistant's personality

Edit `assistant.personality` in your private `config/assistant.yaml`. Describe:

- how the assistant should sound when speaking;
- how concise or exploratory it should be;
- values and boundaries it should follow;
- how it should handle uncertainty and corrections;
- any recurring role, vocabulary, or tone you want.

Keep permanent instructions here and facts about you in the app's explicit
memory feature. Do not commit either file. Start with a short prompt, test real
voice conversations, and refine behavior that you can actually observe.
